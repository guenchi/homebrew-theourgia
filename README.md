# Homebrew tap for Theourgia

    brew tap guenchi/theourgia
    brew install theourgia

Installs `theourgia`, `theourgia-mcp` and `theourgiad`. Chez Scheme and libuv come from Homebrew.
Supported: macOS on Apple Silicon (and Linux under Homebrew on x86_64 and arm64). See
https://github.com/guenchi/Theourgia for the manual.
